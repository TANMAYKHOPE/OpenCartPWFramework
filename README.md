Playwright TypeScript Automation Framework

A scalable and maintainable test automation framework built using Playwright, TypeScript, and Page Object Model (POM). This framework follows the Single Responsibility Principle (SRP) and AAA (Arrange, Act, Assert) pattern to promote clean code, reusability, and easy maintenance.

The framework supports data-driven testing, reusable fixtures, multi-environment configuration, CI/CD execution using GitHub Actions, and detailed test reporting with Allure.

🎯 Key Features

Playwright with TypeScript – Modern browser automation with type safety.

Page Object Model (POM) – Separate page locators and page actions from test logic.

Single Responsibility Principle (SRP) – Keep classes and methods focused on specific responsibilities.

AAA Pattern – Structure test cases using Arrange, Act, and Assert.

Reusable BasePage – Common browser interaction methods such as click, fill, and text retrieval.

Custom Fixtures – Reuse page objects and test setup through fixture injection and destructuring.

Data-Driven Testing – Manage test data using CSV and JSON files.

Reusable Utilities – Dedicated CSV and JSON helper classes.

Environment Configuration – Manage environment-specific settings through configuration files.

GitHub Actions CI/CD – Automate test execution through YAML workflows.

Multiple Test Suites – Support Smoke, Sanity, and End-to-End (E2E) test execution.

Allure Reporting – Generate detailed test execution reports.
